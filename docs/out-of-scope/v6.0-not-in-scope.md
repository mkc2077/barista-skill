# Out-of-Scope — not in v6.0

Following the mattpocock/skills `.out-of-scope` pattern: this file lists
"someone asked about X; here is the specific reason we did not do it".
Future contributors do not need to re-litigate.

## 1. Multi-language translation loop

**Question raised**: could we let GPT translate the entire references/
folder into multiple languages?

**Why not now**: references/ already has a bilingual mirror (zh/en), and
self_check verifies the bilingual-mirror invariant every run. Running an
automated rewriting pass would risk breaking the bilingual-mirror check and
degrade source quality. When a user needs an extra language, ad-hoc
prompting through the chat is cleaner than a one-shot repo rewrite.

## 2. Server / multi-user backend

**Question raised**: the user said "adapt to most providers" — does that
mean this is a SaaS?

**Why not now**: the project is positioned as "local standalone run".
Everything is in the user's localStorage; API keys stay only in their
browser. The first priority is a stable local single-user experience, not
containerized multi-tenancy. See ADR 0001 for the same reasoning on why
PixelRAG / Qwen VL training is deferred.

## 3. Fine-tuned Q-Grader scoring model

**Question raised**: can we train a fine-tuned LLM that does all cupping
scoring and the 22 Q-Grader item rubric for us?

**Why not now**: the MCP tools already produce structured scoring through
reasoning models, and SCA / CVA scoring is a rules-driven artifact. Wiring
a fine-tuned model right now adds model-serving complexity for marginal
accuracy gain. If an offline-only deployment later needs it, revisit. See
ADR 0001 for the same reasoning on the embedding training pipeline.

## 4. Restoring the v5 four-theme set (Light Roast / Pour Over / Dark Roast / Espresso)

**Question raised**: could the four old themes come back as a coffee
"roast progression" gradient?

**Why not now**: v6 collapses four themes to two (Light / Dark). Per ADR
0002, the four-theme set was adding perceptual mass without communication
value. Two themes cover the meaningful preference axis (warm ivory page
vs warm-black page); the accent stays a single hue family per theme.
Adding more themes back is sediment, not clarity.
