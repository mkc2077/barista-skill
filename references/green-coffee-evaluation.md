# 生豆评估完整指南（Green Coffee Evaluation Guide）

> 涵盖 SCA 生豆分级 + 瑕疵豆分类 + 筛网 + 含水率，是 Q-Grader 生豆分级考试与采购品控的完整参考。
>
> **新手转述**：买生豆要看大小、瑕疵、含水率；精品级 = 一级瑕疵 0 + 二级瑕疵 <=5（350g 样品）。

## 零、生豆评估的目的

采购定价 / 品控 / Q-Grader 考试 / 烘焙前置。SCA 生豆分级是精品咖啡行业的基础语言。

## 一、SCA 筛网目数体系

| 目数 | 毫米 | 说明 |
|------|------|------|
| 20 | 8.0 | 特大豆 |
| 18 | 7.10 | 精品级常用下限 |
| 17 | 6.65 | 常见 |
| 16 | 6.20 | 常见 |
| 15 | 5.75 | 部分产区接受 |
| 14 | 5.30 | 过小 |

**产区差异**：肯尼亚大粒（18+）/ 也门小粒（14-15）/ 中美洲多为 16-18。

## 二、含水率与水分活度

| 指标 | 标准 | 理想 |
|------|------|------|
| 含水率 | 10-12% | 10.5-11.5% |
| 水分活度 (aw) | <= 0.7 | < 0.6 |

**测量方法**：烘箱法（精准但慢）/ 电容式水分仪（快速常用）/ aw 仪。

含水率过高 -> 霉变风险；过低 -> 豆体脆弱、风味流失。

## 三、SCA 瑕疵豆分类

### 一级瑕疵（5 个即降级）

| 瑕疵 | 外观 | 原因 |
|------|------|------|
| 全黑豆 | >50% 黑色 | 受热过度/真菌 |
| 全酸臭豆 | >50% 黄褐色 | 发酵过度 |
| 果壳/干果 | 未脱壳 | 脱壳机调校不当 |
| 严重虫蛀 | >=3 虫孔 | 仓储虫害 |
| 真菌感染 | 白/黄霉斑 | 高湿储存 |
| 大块异物 | 石/枝/金属 | 采摘混入 |

### 二级瑕疵（5 个同类 = 1 个一级当量）

局部黑 / 局部酸 / 贝壳豆 / 破碎缺角 / 残留壳皮 / 羊皮层 / 轻微虫蛀 / 浮豆。

详见 `data/defect_beans.json` 与 MCP 工具 `get_defect_bean`。

## 四、SCA 等级表

| 等级 | 一级瑕疵 | 二级当量 |
|------|---------|---------|
| Specialty 精品级 | 0 | <=5 |
| Premium 高级 | 0 | <=8 |
| Exchange 交易所级 | <=1 | <=12 |
| Below Standard | <=1 | <=30 |
| Off Grade | >1 或 >30 | - |

使用 MCP 工具 `get_green_grade(primary_count, secondary_count, screen_size, moisture_pct)` 可自动判定等级。

## 五、Q-Grader 生豆分级考试要点

- 350g 样品，限时（通常 3 盒 x 20 分钟）
- 需挑出全部瑕疵并分类
- 计算瑕疵点数并判定等级
- 与考官判定一致才通过
