# 三角杯测协议（Triangle Test Protocol）

> SCA 三角杯测是 Q-Grader 第5类考试，也是感官训练的核心方法。三杯两同找不同。
>
> **新手转述**：三角杯测就是给你三杯咖啡，两杯一样一杯不同，让你找出来。相似度越高越难。

## 零、三角杯测的目的

感官训练 / Q-Grader 考试 / 产品研发 / 品控一致性。三角杯测是检验品鉴者分辨能力最直接的方法。

## 一、协议标准

- 每轮 **3 杯**（2 杯相同 + 1 杯不同）
- **啜吸雾化**：用杯测匙舀取约 5ml，大口啜吸让咖啡雾化扩散到整个口腔
- **逐一品鉴**：每杯逐一品尝，不要混合
- **通过线**：正确识别 >= 75% 轮数（Q-Grader 考试为 83%）

## 二、难度递进

| 难度 | 差异类型 | 说明 |
|------|---------|------|
| origin | 不同产区 | 最易（风味差异大） |
| process | 不同处理法 | 中等（水洗 vs 日晒） |
| roast | 不同烘焙度 | 较难（浅 vs 中） |
| batch | 同农场不同批次 | 最难（细微差异） |

难度递进原则：从大差异到小差异，逐步提升分辨能力。

## 三、Q-Grader 考试要求

- **4-6 轮**（口径差异：不同版本轮数不同）
- 每轮限时 45 分钟
- **红光教室**：排除通过视觉辨别咖啡粉颜色差异
- 每轮 6 组，每组 3 杯，最多错 1 组
- 通过线 83%

使用 MCP 工具 `get_triangle_protocol(rounds, difficulty)` 可获取参数化协议。

## 四、训练方法

### 自组训练集

1. **入门**：同豆不同烘焙度（浅 vs 中深，差异明显）
2. **进阶**：同产区不同处理法（水洗 vs 日晒）
3. **高级**：同处理法不同产区（埃塞 vs 肯尼亚）
4. **挑战**：同农场不同批次（最难）

### 训练频率

- 每周 2-3 次，每次 3-4 轮
- 每轮后记录判断结果与实际差异
- 错误归因：是温度漂移？啜吸力度不一致？还是真的没分辨出来？

## 五、常见陷阱

1. **三杯顺序记忆干扰**：品到第三杯时已忘记第一杯味道 -> 每杯品鉴后做笔记
2. **温度漂移**：三杯温度不一致导致口感差异 -> 确保同时注水
3. **啜吸力度不一致**：力度不同导致雾化程度不同 -> 保持一致力度
4. **心理暗示**：知道有差异就倾向于"找到差异" -> 盲测，不知道是否有差异
